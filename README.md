# Georgian Railway Map

An interactive map and up-to-date schedule of Georgia's train routes, built with [Hugo](https://gohugo.io/) and the [Hextra](https://github.com/imfing/hextra) theme.

**Live site:** [georailways.com](https://georailways.com)

Available in English, Russian, and Georgian (ქართული).

## What it does

- Renders all active train routes on an interactive map, with geodata pulled from OpenStreetMap.
- Generates a page per route and per station, with schedules, prices, travel time, and so on.

## Project structure

```
content/            Hugo content — routes, stations, directions, blog, about
layouts/            Hugo templates and shortcodes (single-route, single-station, esd_calendar, ...)
data/               Generated data files consumed by the templates (routes.json, stations.json, ...)
static/             Static assets, including generated route geodata and the railway network layer
scripts/            Python scripts that generate the data files from Google Sheets + OSM (Overpass API)
i18n/               Translation strings for en/ru/ka
```

See [scripts/ARCHITECTURE.md](scripts/ARCHITECTURE.md) for a detailed breakdown of what each generation script does.

## Data pipeline

The site's routes and stations data isn't hand-authored — it's generated by the scripts in [scripts/](scripts) from two sources:

- **Google Sheets** — the editorial source of truth for route metadata, schedules, and prices.
- **OpenStreetMap (Overpass API)** — the source of truth for station lists and route geodata.

Running the scripts requires Google Sheets API credentials (service account), which are not included in this repository. In CI, data generation and validation run automatically before deploy; see the [workflows](.github/workflows) for details.

## Development

### Prerequisites

- [Hugo](https://gohugo.io/installation/) (extended version)
- Go (for Hugo modules — see [go.mod](go.mod))
- Python 3 (only needed if regenerating data files — see [requirements.txt](requirements.txt))

### Run the site locally

```bash
hugo server
```

### Regenerate data files

```bash
pip install -r requirements.txt
python scripts/make_routes_files.py         # routes.json, routes-list.js — must run first
python scripts/make_stations_files.py       # stations.json, stations-list.js — depends on routes.json
python scripts/make_railway_network_file.py # the whole railway network geodata for the map
python scripts/make_routes_geo_files.py     # per-route geodata for the map
```

### Tests

```bash
pytest
```

## Deployment

The site is built and deployed to GitHub Pages automatically via [GitHub Actions](.github/workflows/pages.yaml) on push to `main`. A [fast variant](.github/workflows/pages-fast.yaml) is available for manual deploys that skips route validation and geodata regeneration.
